# 2. Go to your favorite website and try to view the page source and write the exact lines of code. 
    Does it clone the website? why?

        We can see page's source code by pressing [ctrl + u]. No, viewing the page source does not
     completely clone the website. The page source mainly shows the HTML code and references to 
     CSS and JavaScript files. A website may also depend on images, databases, server-side code,
     APIs and other resourses. Therefore, copying the page source alone is not enough to create an
     exact working clone of the website.
